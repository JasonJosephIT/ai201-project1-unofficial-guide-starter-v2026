Optional. The key is stored only in this browser and sent only to Google's Gemini API (generativelanguage.googleapis.com), never to this site. Without one, you get the closest passages instead of a written answer. The first question downloads the embedding model (about 90 MB), which your browser then caches.

Answers come from serve.py in your project. Start it with python serve.py (or PORT=5050 python serve.py if macOS AirPlay already holds port 5000), then point this at it. Safari blocks secure pages from calling http://localhost; use Chrome, Edge or Firefox, or open this page from python -m http.server in the docs/ folder.

Corpus

How this works

  1. Retrieve. Your question is embedded and compared with every chunk of the chosen corpus.
  2. Gate. If even the closest chunk is further away than the cutoff, the system refuses rather than guess.
  3. Answer. Otherwise the model answers using only those chunks and names its sources. On this page without a Gemini key, you get the closest passages instead.

Every answer below shows all three steps, so you can see why it said what it said.

Lower distance is closer. Cutoff and top-k come from config.py; chunks from chunker.py::split_documents.
